# Mizuki Releases (Official Downloads)

Official public distribution repository for **Mizuki (瑞気)** — High-Performance Anime & Media Torrent Streaming Client for Windows and Android.

## Download Latest Releases

Please check the **[Releases Tab](https://github.com/Sylent-Sys/mizuki-releases/releases)** for all official binary downloads, installers, and SHA-256 checksums.

- **Windows 10/11 (64-bit):** `Mizuki-Setup-<version>.exe` / `Mizuki-Setup-x64.exe` (Installer) or `Mizuki-Windows-x64-<version>.zip` (Portable)
- **Android 10+ (Split per ABI):**
  - `Mizuki-Android-arm64-v8a-<version>.apk` (Most modern phones & tablets)
  - `Mizuki-Android-armeabi-v7a-<version>.apk` (Older 32-bit ARM devices)
  - `Mizuki-Android-x86_64-<version>.apk` (x86_64 tablets & emulators)

## Auto-Update Manifest
